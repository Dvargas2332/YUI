# Extensiones de YUI

Las extensiones representan integraciones más ligeras o packs de capacidades.

Cada extensión vive en su carpeta y declara un `extension.json`.

```json
{
  "id": "mi-extension",
  "name": "Mi Extensión",
  "version": "0.1.0",
  "description": "Qué amplía dentro de YUI",
  "entrypoint": "extension.py",
  "enabled": true
}
```
